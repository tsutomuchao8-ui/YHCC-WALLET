YHCC WALLET 4.0

BITCOIN SELF-CUSTODY LIGHT WALLET

YOUR KEYS. YOUR BITCOIN. YOUR CONTROL.

YHCC WALLET 是一款专注于 Bitcoin 主网的非托管轻钱包项目。

我们的目标是打造安全、轻量、便捷的比特币资产管理工具，让用户自主掌握钱包密钥，并直接连接真实的比特币区块链网络。

核心功能

- Wallet Creation：创建全新比特币钱包。
- Mnemonic Backup：支持 12 / 24 个单词的助记词备份方案。
- Self-Custody：用户自主控制钱包密钥。
- BTC Receive：生成比特币收款地址及二维码。
- BTC Transfer：构建、本地签名并广播比特币交易。
- Bitcoin Mainnet：连接真实比特币主网。
- Transaction History：查询链上交易记录。
- Wallet Security：钱包备份及安全管理。

产品定位

- 网络：Bitcoin Mainnet
- 钱包类型：Non-Custodial Wallet
- 技术方向：Bitcoin Light Wallet
- 资产范围：BTC
- 设计风格：Black & Gold

开发原则

1. 用户自主控制密钥。
2. 私钥和助记词不得上传至服务器。
3. 交易签名在用户设备本地完成。
4. 保持界面简洁与操作透明。
5. 所有真实交易必须经过用户明确确认。

项目状态

YHCC WALLET 4.0 正在开发中。以上功能属于开发目标，实际可用性以完成实现和安全测试为准。
